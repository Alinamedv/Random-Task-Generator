# Random Task Generator - Генератор случайных задач
**Автор:** Алина Медведева

**Дата создания:** Май 2026

## Описание программы

Random Task Generator — это GUI‑приложение на Python, которое генерирует случайные задачи из предопределённого списка. 

### Возможности

* генерировать случайные задачи;
* фильтровать задачи по типам (учёба, спорт, работа);
* добавлять новые задачи;
* просматривать историю сгенерированных задач;
* сохранять историю в JSON‑файл.

## Инструкция по запуску

### Требования

* Python 3
* tkinter — для создания графического интерфейса;
* random — для генерации случайных задач;
* json — для сохранения и загрузки истории.

### Запуск

1. Выберите тип задачи («все», «учёба», «спорт», «работа») в выпадающем списке.

2. Нажмите «Сгенерировать задачу» — результат появится в центре окна и добавится в историю (последние 50 задач внизу).

3. Чтобы добавить свою задачу: введите текст в поле «Новая задача», выберите тип, нажмите «Добавить задачу». При пустом поле будет ошибка.
